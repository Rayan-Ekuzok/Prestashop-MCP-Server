# Customer overview

Give the merchant two numbers: how many customer accounts the shop has, and how
many were created recently.

1. Call `mymodule-count_customers` without arguments for the total.
2. If a date is given under *This request* below, call it again with `since`
   set to that date. If none is given, ask the merchant which period they mean.
   Do not pick one yourself.
3. Answer in two short lines. Say which shop the numbers come from if the
   merchant runs several.
